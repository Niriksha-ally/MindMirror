# 🌿 MindMirror

## Track. Analyze. Discover. Reflect.

MindMirror is a personal wellbeing pattern analyzer designed to help users understand their everyday wellbeing through their own personal data.

Users can record their mood, stress, energy, sleep, daily goals, and diary entries.

---

## ✨ Features

- 🏠 Home page
- 📊 Wellbeing dashboard
- 🙂 Mood tracking
- 😟 Stress tracking
- ⚡ Energy tracking
- 🌙 Sleep tracking
- 🎯 Daily goal tracking
- 📔 Personal diary
- 📋 Check-in history
- 🔍 Personal pattern detection
- 📈 Wellbeing averages
- 💾 MongoDB data storage
